# SCREENSHOTS

Captures from Bort's own live KNOX Console V6.4 build, taken 25 November
2026 on the YQ10S tablet / bench setup. 1280 x 800 each.

| File | Shows |
|---|---|
| `nightstand.png` | Nightstand page: clock 2:56 PM, Wednesday 25 November, moon, next-hours forecast, sleep timer. |
| `sleep-wind-down.png` | Sleep page: wind-down radio (Nightride FM, Smooth Chill, Smooth Relax), volume 90%, full moon 100% lit, Goodnight / Screen Off / All Quiet / Mute. |

## EXCLUDED

The build had 38 screenshots in the source folder. Only the two above
are in this repo.

- One screenshot of an FMHY stream-aggregator listing was **not**
  included. It is a third-party link list, not the console's own UI,
  and it does not belong in a public repo for this project.
- The other 35 captures were not reviewed one by one for this release.
  They stay out until each one is checked for personal information.
  Nothing was published on the assumption that it was clean.

If a screenshot here ever shows something personal, say so and it comes
out — no argument, no delay.

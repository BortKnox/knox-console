# CONTRIBUTING

Bug reports and focused fixes are welcome; response times are not guaranteed.

## BEFORE YOU SEND ANYTHING

Strip API keys, tokens, client IDs, personal paths and personal information
from any log, config or screenshot you attach. Do not send a live config —
send the smallest excerpt that shows the problem, with secrets replaced.

## WHAT FITS

- A fix that fits the existing design: AMOLED dark, mint accent `#80d7bd`,
  flat, radius 16, no shadows.
- A correction to the docs, the page inventory or the example config.
- A widget that earns its place. Bloated dependencies do not.

## WHAT DOES NOT

- Redesigns of the layout, or removing something that is wired in.
- Deleting something unwired and presenting that as a fix.
- Feature requests that turn a personal bench tool into a product.

Personal project, shared as is. Forking is welcome.
